02

專案範圍

  1. 使用 WordPress + Elementor 建置多頁式形象網站。
  2. 首頁包含門市資訊、電話、Google 地圖 / 連結、完工大圖、主要產品入口、精選完工案例與免費丈量 CTA。
  3. 產品服務包含客戶指定分類入口；各分類得依內容量使用共用 Elementor 產品模板，不代表每一類均製作完全不同版型。
  4. 建立完工案例後台：可管理標題、封面、Gallery、地區、產品、空間、風格、日期、摘要、需求、解法、草稿 / 發布；新增案例不需重新使用 Elementor 排版。
  5. 建立基礎 Local SEO：主要頁 title / description、LocalBusiness Schema、Sitemap、Google Maps、RWD 及 Search Console 串接協助。
  6. 依甲方確認的 9 組舊 URL → 新 URL 對應建立 301，並協助正式 DNS 切換。
  7. 交付 WordPress Highest Administrator，並提供一次線上教學 / 錄影與交接。

主力產品　布簾、遮光窗簾、蛇形簾、調光捲簾、捲簾、羅馬簾、門簾。

網站分類　布簾、遮光窗簾、蛇型簾 / 蛇簾、調光捲簾、蜂巢簾、羅馬簾、塑膠拉門、壁紙、木百葉、片簾、紗簾等。
